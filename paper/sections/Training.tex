The MPDenoiseNet network was trained using a dataset of 432 randomly selected grayscale images\cite{Rafiee2021}. To augment the training data, a custom data loader was implemented. This loader extracted $64 \times 64$ pixel patches from the full images with a stride of 10 pixels, significantly increasing the effective dataset size.

To further enhance the robustness and generalization of the model, online data augmentation was applied during training. Each image patch was subjected to a random transformation chosen from the following set: [Vertical Flip, Horizontal Flip, Random Rotation ($90^\circ, 180^\circ, 270^\circ$)]

These transformations were each applied with equal probability. The generated patches were then split into training and testing sets, with a 80\%/20\% split.

The MPDenoiseNet model was trained for a total of 250 epochs. Optimization was performed using the Adam Optimizer \cite{adam}. The loss function employed was a custom \textbf{MixL1SSIMLoss}, designed to leverage the benefits of both L1 and Multi-Scale Structural Similarity Index Measure (MS-SSIM) metrics \cite{Zhao2017}. This loss function, implemented as a PyTorch module based on \cite{Pessoa2023}, is a linear combination of L1 loss and an MS-SSIM-inspired loss, controlled by a weighting factor $\alpha$ set to 0.84. The MS-SSIM component is approximated using Gaussian kernels of varying sigmas to capture structural similarity at multiple scales, while the L1 component encourages pixel-level accuracy. This combined loss function aims to achieve a balance between perceptual quality (SSIM) and pixel-wise fidelity (L1).

Mathematically, let $x$ be the predicted image and $y$ be the ground truth image. The \texttt{MixL1SSIMLoss} ($\mathcal{L}_{Mix}$) combines a structural similarity term and a pixel-wise error term using a weighting factor $\alpha=0.84$:
\begin{equation} \label{eq:mix_loss}
\mathcal{L}_{Mix}(x, y) = \alpha \cdot \mathcal{L}_{SSIM\text{-}like}(x, y) + (1 - \alpha) \cdot \mathcal{L}_{G\text{-}L1}(x, y)
\end{equation}
The term $\mathcal{L}_{G\text{-}L1}$ represents the L1 loss ($|x - y|$) averaged with Gaussian weighting applied across multiple scales. The term $\mathcal{L}_{SSIM\text{-}like}$ is inspired by the Multi-Scale Structural Similarity Index Measure (MS-SSIM) \cite{Zhao2017}. It evaluates structural similarity by comparing luminance, contrast, and structural information derived from local image statistics computed using multiple Gaussian filters. The final loss value used during training is scaled by 100. This approach balances pixel-level accuracy with perceptual similarity.


Training was performed on a machine with nVidia L4 GPU with 24GB.
